Project Title : React Native Timer App.

I've done this using REACT NATIVE EXPO (For windows machine)

to install

git clone
npm install
npx expo start


What I've done in this project

 * Add and manage multiple timers.
 * Start, pause, and reset timers individually or in bulk
 * Progress bar visualization for each timer
 * Persistent storage using AsyncStorage
 * Light mode and Dark Mode
 * React Native Paper (for UI components like ProgressBar)
